## 🚀 Backend — API REST em Java (Spring Boot)

### 📁 Estrutura do diretório `backend/`

```text
backend/
├── src/
│   └── main/
│       ├── java/
│       │   └── br.com.hemn.backend/
│       │       ├── backend/      
│       │       ├── controller/
│       │       ├── model/
│       │       └── repository/
│       └── resources/
│           ├── templates/
│           │   └── cardapio.html
│           └── application.properties
├── doc/
│   └── index.html
└── pom.xml
```

O backend do projeto HEMN foi desenvolvido utilizando **Java 21** e **Spring Boot**, seguindo uma arquitetura organizada em camadas para facilitar manutenção, testes e escalabilidade.

### 🔧 Tecnologias Utilizadas
- **Java 21**
- **Spring Boot**
- **Spring Web**
- **Spring Data JPA**
- **PostgreSQL Driver**
- **Maven**
